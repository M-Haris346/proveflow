# Threat model v0 [mixed status: see the tag in each row]

> Threats **to proveflow and its user** — this tool reads secret-bearing configs and runs attack
> payloads, so it is itself an attack surface. Each threat maps to a control and a test.
> Status: mixed. Rows tagged [impl][tested] are built and tested in the phase named in the row
> (Phase 1: T1, T2, T8, T10-T16; Phase 2: T3, cassette validation in T6). Every other row is
> still [planned]: its control is built in the phase that builds the component.
